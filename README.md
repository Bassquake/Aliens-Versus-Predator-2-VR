# Aliens Versus Predator 2: VR
PCVR mod for Aliens Versus Predator 2 (2001) game. This is only for Windows 10 and above. Untested on Linux using Proton. Should work on medium graphics cards from Nvidia 2060 and upwards.

> [!CAUTION]
> You need the original installation game files. The 2 disc CD version can be found on eBay or maybe archive.org.

## Installation
- Install the Aliens Versus Predator 2 game using it's default folder location. (C:\Program Files (x86)\Fox\Aliens vs. Predator 2).
- Download the zip in Releases and extract to a folder like so: **C:\proj\avp2xr**
- In the avp2xr folder, right click the **install.bat** and Run as Administrator. This will install the necessary dlls and files into the game folder.
- Now double click AVP2 VR.bat to start the game.

### Tips
To turn off various game settings, run the AVP2.exe in the **C:\Program Files (x86)\Fox\Aliens vs. Predator 2** folder, you will be presented with a popup:

![AvP2 Options 1](https://github.com/Bassquake/Aliens-Versus-Predator-2-VR/blob/master/captures/avp2-options-1.jpg)

Choose Options and you'll see a list of options:
![AvP2 Options 2](https://github.com/Bassquake/Aliens-Versus-Predator-2-VR/blob/master/captures/avp2-options-2.jpg)

I like to **Disable Logos** so they don't keep loading every time I start the game.

Changing the resolution alters the menus and HUD size. Set it to 800 x 600 x 32 for now. The lower the rez the larger the HUD, the higher the rez the smaller the HUD and text is difficult to read.

![AvP2 Options 3](https://github.com/Bassquake/Aliens-Versus-Predator-2-VR/blob/master/captures/avp2-options-3.jpg)

Click PLAY so settings apply. Quit the game and then run AVP2 VR.bat in C:\proj\avp2xr so it runs the VR version properly.

## Controls
I've tried to map as many of the functions to the buttons. They can be customised by editing the **avp2xr.ini** located in **C:\proj\avp2xr\deploy**. Other settings can be found in there to customise positioning of HUD and weapons.
